# Contributing

Thanks for helping improve N-Body Universe.

## Local Workflow

1. Install Node.js 22 or newer.
2. Run `make install-hooks`.
3. Run `make test` and `make smoke` before pushing.
4. Use Conventional Commits, for example `feat: add resonance monitor`.

## Code Style

Keep changes scoped, prefer existing patterns, and add tests for simulation math, user-facing behavior, and build/runtime contracts.
