# N-Body Universe

Browser-based gravitational sandbox powered by REBOUND compiled to WebAssembly, Three.js rendering, and orbital Web Audio harmonics.

Live site: https://baditaflorin.github.io/n-body-universe/

Repository: https://github.com/baditaflorin/n-body-universe

Support: https://www.paypal.com/paypalme/florinbadita

## Status

This repository is being implemented as a pure GitHub Pages application. The first publishable placeholder lives in `docs/`; the production app will continue to build into `docs/` so Pages can serve it directly.

## Quickstart

```sh
make install-hooks
make dev
make test
make build
make smoke
```
